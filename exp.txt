# 4. AJAX-Based Web Applications

### 1. Aim

To develop an AJAX-based web application that retrieves data from a server asynchronously without reloading the entire web page.

### 2. Algorithm

1. Start the program.
2. Create an HTML page with a button and a display area.
3. Create a JavaScript function named `loadData()`.
4. Create an `XMLHttpRequest` object.
5. Open a connection to the data source using the `open()` method.
6. Set the request method as GET.
7. Send the request using the `send()` method.
8. Check whether the request is successfully completed.
9. Retrieve the response data from the server.
10. Display the data on the web page using DOM manipulation.
11. If an error occurs, display an error message.
12. Stop the program.

### 3. Program

```html
<!DOCTYPE html>
<html>
<head>
    <title>AJAX Web Application</title>
</head>
<body>

    <h2>AJAX Web Application</h2>

    <button onclick="loadData()">Load Data</button>

    <p id="result">Click the button to load data.</p>

    <script>
        function loadData() {

            var xhttp = new XMLHttpRequest();

            xhttp.onload = function() {

                if (this.status == 200) {
                    var data = JSON.parse(this.responseText);

                    document.getElementById("result").innerHTML =
                    "Title: " + data.title + "<br><br>" +
                    "Body: " + data.body;
                }
                else {
                    document.getElementById("result").innerHTML =
                    "Error loading data!";
                }
            };

            xhttp.open("GET",
            "https://jsonplaceholder.typicode.com/posts/1", true);

            xhttp.send();
        }
    </script>

</body>
</html>
```

# 6. REST API Development and Database Connectivity

3. Install the required packages: Express, MySQL2, and CORS.
4. Import the required modules.
5. Create an Express application.

   * GET – Retrieve student details.
   * POST – Insert new student details.
   * PUT – Update student details.
   * DELETE – Delete student details.
8. Receive client requests through API endpoints.
9. Execute the corresponding SQL queries.
10. Send the database result as a JSON response.
11. Start the server on port 3000.

13. Stop the program.

### 3. Program

**Step 1: Install Required Packages**

Open the terminal and execute:

```bash

npm install express mysql2 cors
```

**Step 2: Create Database and Table**

Open MySQL and execute:

```sql

    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100),

    department VARCHAR(100)
```

The following is the complete simplified program.

```javascript
// Import modules
const express = require("express");
const mysql = require("mysql2");
const cors = require("cors");

// Create Express app
const app = express();

app.use(express.json());
app.use(cors());

// Connect to MySQL
const db = mysql.createConnection({
    host: "localhost",
    user: "root",
    password: "",
    database: "studentdb"
});

// Check database connection
db.connect((err) => {
    if (err) {
        console.log("Database connection failed");
    } else {
        console.log("Connected to MySQL database");
    }
});

// GET - Display students
app.get("/students", (req, res) => {
    db.query("SELECT * FROM students", (err, result) => {
        if (err) {
            res.send(err);
        } else {
            res.json(result);
        }
    });
});

// POST - Add student
app.post("/students", (req, res) => {
    const { name, email, department } = req.body;

    db.query(
        "INSERT INTO students (name, email, department) VALUES (?, ?, ?)",
        [name, email, department],
        (err, result) => {
            if (err) {
                res.send(err);
            } else {
                res.json({ message: "Student added successfully" });
            }
        }
    );
});

// PUT - Update student
app.put("/students/:id", (req, res) => {
    const { name, email, department } = req.body;
    const id = req.params.id;

    db.query(
        "UPDATE students SET name=?, email=?, department=? WHERE id=?",
        [name, email, department, id],
        (err, result) => {
            if (err) {
                res.send(err);
            } else {
                res.json({ message: "Student updated successfully" });
            }
        }
    );
});

// DELETE - Delete student
app.delete("/students/:id", (req, res) => {
    const id = req.params.id;

    db.query(
        "DELETE FROM students WHERE id=?",
        [id],
        (err, result) => {
            if (err) {
                res.send(err);
            } else {
                res.json({ message: "Student deleted successfully" });
            }
        }
    );
});

// Start server
app.listen(3000, () => {
    console.log("Server running at http://localhost:3000");
});
```
